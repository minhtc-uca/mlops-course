Only reviewed student-facing materials belong on this branch. Editable sources,
instructor notes, drafts, references and class/group records are kept in the
instructor's private repository.

## Clone only the materials branch

```bash
git clone --single-branch --branch materials https://github.com/minhtc-uca/mlops-course.git mlops-materials
```

Add `--depth 1` if you only need the latest version. The student starter is on
[`main`](https://github.com/minhtc-uca/mlops-course/tree/main), which can be cloned
separately with `--single-branch --branch main`.
