# Later sessions: not implemented in this starter

- Week 2, Labs 3–4: dependency locking, Docker build and clean-environment rerun;
  prediction API with input validation and containerized tests. Load the trusted
  saved model without training during startup or requests.
- Week 3, Labs 5–6: service deployment, structured logging and model-version
  checks; GitHub Actions, CI checks and regression tests. Observe real failing and
  repaired workflow runs.
- Week 4, Labs 7–8: training pipeline, model evaluation and quality gate (a reject
  preserves the accepted artifact); service monitoring, incident diagnosis and
  verified rollback.
- Week 5: project clinic, final verification and team presentations. The final
  submission is GitHub Release v1.0.0 with one final held-test evaluation of the
  already selected release candidate. No new lab or weekly report.

API payloads, thresholds, later commands and workloads require their own review
and pilot. This list is not evidence that those features exist.
